# PSFDF – Volunteer Website Testing

## Project Overview

**Type:** Volunteer Website Testing  
**Testing Approach:** Manual & Functional Testing  
**Platforms:** Desktop, Mobile & Tablet

As part of a volunteer testing initiative with PSFDF, I participated in testing a website to identify functional issues, navigation problems, performance concerns, and potential improvements.

The objective was to evaluate the website's main features and provide feedback to help improve its usability and overall functionality.

## Testing Activities

The testing covered several website components:

- **Forms:** Verification of the contact, recruitment, and fire-reporting forms.
- **Navigation & Social Media:** Checking navigation links and Facebook sharing functionality.
- **Interactive Map:** Observing loading performance and filter selection.
- **Website Display:** Checking favicon visibility across different pages.
- **SEO & URLs:** Reviewing URL consistency with menu titles.

## Issues Identified & Recommendations

| Website Component | Findings |
|---|---|
| Fire Reporting Form | Non-functional form |
| Facebook News Sharing | Redirects to a page not found |
| Ongoing Fires Map | Slow loading when displaying the map and selecting filters |
| Contact Form | Recommendation to add a phone number field |
| Recruitment Form | Recommendation to add mandatory CV and cover letter PDF upload fields |
| Favicon | Missing on certain pages, including the map and legal information pages |
| SEO – URLs | Recommendation to align page URLs with the corresponding menu titles |

## Deliverables

- Website testing and issue identification.
- Feedback and improvement suggestions.
- Excel testing report containing observations and supporting screenshots.
